      Einstellungen

      Als App installieren

      1 · Skript schreiben

      Kostenlos auf aistudio.google.com unter „Get API key“, ohne Kreditkarte. Lade keine vertraulichen Firmenunterlagen hoch.

      2 · Stimmen

      Die Qualität hängt vom Gerät ab. iPhone: Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch, dort eine Stimme mit „Premium“ oder „Erweitert“ laden. Windows: die App im Edge-Browser öffnen, dort gibt es natürliche Online-Stimmen.

      Am natürlichsten klingen deutsche Muttersprachler-Stimmen. Füge in der ElevenLabs Voice Library drei deutsche Stimmen zu „My Voices“ hinzu und lade sie dann hier.
